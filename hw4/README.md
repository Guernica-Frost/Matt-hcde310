# HW4: Artwork Search

For anyone who wants to quickly find artworks by an artist in the Art Institute of Chicago's collection.

## How to run

```
cd hw4
pip install flask requests
flask --app app run --debug
```

Then open http://127.0.0.1:5000 in your browser, type an artist name (for example 'monet'), and press **Find artworks**.
